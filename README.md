# 3D Portfolio – Emmanuel Dominguez

Interactive 3D portfolio featuring a custom programmer desk setup modeled in Blender and integrated with Three.js.

🔗 **Live Demo:** [https://Emmanuel123159.github.io/mi-portafolio-3d/](https://Emmanuel123159.github.io/mi-portafolio-3d/)

## 🔧 Technologies

- **Blender** – 3D modeling, GLTF export  
- **Three.js** – WebGL rendering, OrbitControls, particles  
- **HTML5/CSS3** – Responsive layout, dark/light mode  
- **JavaScript (ES6)** – Interactivity (color shift, auto-rotate)  

## ✨ Features

- Interactive 3D scene (rotate, pan, zoom)  
- Custom GLTF model (desk, monitor, keyboard, mouse, laptop, plant)  
- Dark/Light mode toggle  
- Color shift (changes lights and background)  
- Auto-rotate (5 seconds)  
- Floating particles  
- Responsive design  
- Rive demo placeholder

## 🛠️ Local Setup

1. Clone the repo: `git clone https://github.com/Emmanuel123159/mi-portafolio-3d.git`  
2. Run a local server (Live Server, `npx http-server`, or Python `http.server`)  
3. Open `index.html` in your browser
